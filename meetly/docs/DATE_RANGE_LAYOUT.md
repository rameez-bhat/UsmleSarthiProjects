# Date range layout

Each range now contains its calendar and its own date/time controls in one card. The first range no longer uses a separate Choose times section below all later ranges. On desktop the calendar sits beside its controls; on narrow screens controls stack directly below the same range's calendar. Other single/multiple-date time controls keep their original location.

Calendar headers use dedicated flex styling so month navigation no longer inherits the form's two-column grid. Calendar width is capped at 420px.

No scheduling calculation, saved slots or backend changes. Rebuild and deploy Hosting only.
