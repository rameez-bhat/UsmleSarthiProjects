# Remove dates and times

Each date/time input has a Remove button. In the schedule preview, click a time
chip to remove that appointment only, or Remove date to remove all appointments
on that date. Restore removed preview times undoes preview exclusions. Save the
event to persist changes. Existing published appointments remain separately
editable with Remove under Existing saved appointments.

Frontend-only change: run npm run build and deploy your existing scheduler
Hosting target. No new function deployment is required for these controls.
