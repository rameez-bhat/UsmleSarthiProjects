# Editing saved slots in a calendar

Opening an event or Manage your slots now shows a calendar for existing saved appointments. Every saved date is highlighted, with an appointment count. Selecting one shows only that date's editable host/time rows. Editing a date or time preserves all other rows. Navigating months does not change the schedule. More than eight appointments on the selected date remain behind Show more / Show less.

The separate host schedule cards add new times; the saved calendar edits existing times. This does not reconstruct old range-builder definitions from expanded appointment rows.

Question controls now share one compact footer: Required on the left and an accessible trash-icon Remove question action on the right.

Rebuild and deploy Hosting only. No new backend changes.
